#+title: Regards — rédactions mathématiques

* Le site

Regards propose aux enseignants de lire et noter des rédactions, puis de les situer sur trois axes indépendants : Confus–Lisible, Vague–Précis et Fautif–Valide. Le parcours comprend un essai guidé, une lecture progressive, trois barres à billes numérotées et une vue libre en trois dimensions.

La note va de 0 à 3 par quarts de point. Chaque coordonnée va de −10 à +10 en interne ; les axes affichent seulement le repère du milieu. Le zéro correspond à un attendu contextualisé. Les réponses restent dans la page jusqu’à leur export JSON ; aucun envoi automatique n’est effectué.

Seul ~docs/site/~ est publié par GitHub Pages. La construction de la banque publique conserve une liste explicite de champs et exclut les codes, corrigés et annotations de recherche. Le dépôt source étant public, cette exclusion ne constitue pas une confidentialité des sources internes.

* Développer et vérifier

Depuis ~docs/~, avec Node.js 22.12 ou plus récent et Python 3 :

#+begin_src sh
npm ci
npm run build:main
npm run dev -- --host 0.0.0.0
#+end_src

La compilation met à jour le prototype historique et le parcours Regards, puis construit la banque publique. L’aperçu Vite utilise le port 4173 ; le site publié est statique et n’en dépend pas.

#+begin_src sh
npm run build:data
node scripts/test-survey.cjs
npm run test:logic
npm run test:e2e:install
npm run test:e2e
#+end_src

Les tests de navigateur lancent automatiquement un serveur statique si nécessaire. Pour Guix, utiliser ~npm run test:e2e:guix~. Les commandes standard n’appliquent pas de correctif spécifique à Guix.

Une modification de ~research/bank.json~ doit être suivie de ~npm run build:data~. Cela régénère la banque publique, les notices Org et l’audit. Les identifiants de question et rédaction doivent rester stables au sein d’une version ; un changement de corpus exige une nouvelle version pour l’analyse des exports.

* Données exportées

Le schéma 2 précise ~interactionMode: axis-sliders~ et contient la version de banque, les niveaux, la graine et les ordres de présentation, les notes initiales et révisées, les coordonnées et leurs axes évalués, les questions passées et un journal horodaté des interactions. L’essai guidé est exclu. Une coordonnée à zéro dont l’axe n’est pas dans ~evaluatedAxes~ représente une absence de jugement, pas une réponse zéro.

Le détail des choix méthodologiques et des limites de collecte se trouve dans ~research/protocole.org~.
